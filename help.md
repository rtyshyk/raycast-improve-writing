# Setup

Improve Writing sends the text you select to [OpenRouter](https://openrouter.ai), so it needs an OpenRouter API key.

1. Sign in at [openrouter.ai](https://openrouter.ai) and create a key on the [Keys page](https://openrouter.ai/keys).
2. Paste it into **OpenRouter API Key**.

The default model is `openai/gpt-6-luna`. You can change it here, or press ⌘M after the first result to pick from every OpenRouter model with its price.
